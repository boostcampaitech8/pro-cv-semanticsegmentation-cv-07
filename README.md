## Project Overview

본 프로젝트는 Hand Bone X-ray 이미지를 활용하여 뼈 영역을 정밀하게 분할하는 Bone Segmentation 모델 개발을 목표로 한다. 이를 통해 골절 진단, 수술 계획 수립, 맞춤형 의료 장비 제작 등 의료 현장에서의 진단 정확도와 업무 효율성 향상에 기여하고자 한다.
